# shiyanshi

这是我的个人 AI 实验室，用于探索、测试和记录 AI Agent、自动化工具以及网页项目。

## 项目定位

shiyanshi 是我的 AI 技术实验空间，主要用于：

- **AI 智能体实验**：测试不同 AI Agent、模型能力以及协作开发流程。
- **自动化工具实验**：探索脚本、工作流和日常效率工具。
- **网页项目实验**：开发简单 Web 应用、界面原型和功能验证项目。

## 当前状态

这是一个持续迭代中的实验仓库。

项目特点：

- 以简单、清晰、易维护为目标。
- 优先验证想法，再逐步完善功能。
- 使用 GitHub Actions 自动发布网页项目。

## 技术方向

- HTML / CSS / JavaScript
- GitHub Actions
- AI Agent 工作流
- 自动化开发流程

这是个人学习与实验用途项目。
